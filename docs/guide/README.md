# 指南

这套文档按"你要做的事"分块，不必从头读到尾。

| 这一块 | 解决什么问题 |
|---|---|
| **起步** | 打包、部署、跑通第一间教室 |
| **喊话** | 文字 / 语音 / 图片怎么发，显示成什么样，怎么一次发给多个班，怎么定时发 |
| **课堂** | 学生名单、快速呼叫、语音转文字字幕 |
| **教室端** | 屏幕弹窗、与 ClassIsland 联动、教室端的各项设置、PIN 保护 |
| **服务器** | 中继服务器怎么部署、管理控制台、分享链接 |

## 三个组件，先分清

- **教室端**：教室里那台常年开着的电脑。它负责出声、出画面，也是唯一"知道教室里到底发生了什么"的一端。
- **教师端**：老师自己手机上（或电脑上）的那个应用。它只负责发。
- **中继服务器**：只在两端**不在同一个网络**时才需要。同一个 Wi-Fi 下，教室端与教师端直接连，不需要服务器。

> 后面很多设计取舍都源自一个前提：**教室里那台机器是共用的、常年开着的，而且没人看着**。
> 所以"重置教室身份""退出程序"这类动作要么被保护起来，要么干脆不给入口。
