# 跑通第一个班级

按顺序做完，就有一个能用的班级了。

## 1. 教室端连服务器（跨网络时才需要）

教室端 → 设置 → 「跨局域网喊话」→ 填服务器地址（例如 `https://relay.example.com`）→ 连接服务器。

首次会在服务器上注册并生成口令，界面上出现本教室的 **UUID** 与 **口令**，都能一键复制。

> 同一局域网内的教室不必做这一步：教师端打开就能自动发现它。

**这两项在教室端是只读的**：看得到、复制得到，但没有"重新生成"的按钮。
教室里那台机器是给值班老师和学生共用的，而"重置"的真实含义是
"这台电脑从此变成另一间教室"—— 已绑定的教师端全部失效、口令要重新抄给每一位任课老师。
一个误触就要把口令重发一圈，这个代价和"重置"这个词给人的感觉完全不成比例。
真要重来（比如这台机器换教室了）请到服务器控制台上做。

## 2. 老师注册账号

教师端 → 「设备」页 → 没有账号？切换到注册 → 填用户名（3~20 位、字母开头）、
邮箱、**姓名**、**任教科目**（选填）、口令 → 注册并登录。

- **姓名**会显示在教室端的弹窗上，请填真名。
- **任教科目**填了之后，教室里看到的来源就是「数学张老师」——
  同一间教室一天里有好几位老师来喊，只报姓名往往对不上人。
  同一位老师在不同班教不同科目的话，注册时先填一个默认的，
  之后在设备页的「任教科目」卡里**按班级各填一份**（留空＝用默认那份）。

## 3. 把班级给老师

两条路，选一条：

| 路径 | 做法 | 适合 |
|---|---|---|
| **分配绑定**（推荐） | 管理员打开控制台用 admin 登录 → 「教室」页 → 找到该班级 → **授权给老师** | 学校统一管理 |
| 口令绑定 | 把教室端的 UUID 与口令抄给老师，老师填进「绑定教室」卡片 | 没有控制台、或临时用一下 |
| **分享链接** | 控制台勾几个班 → 「分享选中的班级」→ 把链接发给老师 | 一次给好几个班，且不想让口令在聊天软件里流传 |

分享链接那条路最省事：老师点开链接（或把链接粘进教师端）就把这几个班加到自己账号下，
之后点一下就绑定。详见 [分享链接](/guide/share.html)。

## 4. 老师绑定教室

- 授权或分享链接来的班级：在「管理员分配的班级」里点一下即可；
- 口令绑定：把 UUID 与口令填进「绑定教室」卡片，点「绑定教室」。

绑定成功后顶栏会显示教室名。**绑定过的教室会存在这台设备上**，
卡片下方多出一段「已保存的教室」，点一下就能切过去（口令也一并存着）。

> 这里有个必须说清的取舍：**口令是以明文存在教师端本机的**。
> 原来刻意不存，理由是"留在老师脑子里更安全"—— 但那个理由在"一个老师教好几个班"面前站不住：
> 口令是绑定的唯一凭据，不存它，每次换班上课都要重新找管理员要一遍，这个功能就等于没做。
> 代价是这台设备被拿走就等于能绑定这几间教室并朝它们喊话；
> 不过同一个文件里本来就存着登录令牌（那同样是能喊话的凭据），新增的暴露面其实很小。
> 不想要哪一间，在列表里移除即可，口令一并删掉。

## 5. 验证

老师发一条文字喊话。教室里应当听到朗读，屏幕边缘弹出提示卡，
教师端顶栏显示当前链路（同网段是「局域网直连」，跨网络是「公网中继」）。

没反应的话看 [排错](/reference/troubleshooting.html)。
