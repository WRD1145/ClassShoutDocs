# PIN 分项保护

教室里那台电脑是共用的，路过的人可以随手改配置、甚至把整个教室端关掉。
「设置 → 设置口令」提供两层保护，可以只开其中一层：

| 这一层 | 管什么 |
|---|---|
| 进入设置需要 PIN | 打开设置窗口之前先验一次；关掉窗口后重新上锁 |
| 这几项要单独输 PIN | 勾中的项目在设置里显示为灰色，要输 PIN 才能改 |
| 退出程序也需要 PIN | 托盘菜单里的「退出」会先要 PIN |

可分项保护的有六项：朗读设置、**语音转文字与密钥**、跨局域网与教室身份、
喊话展示与弹窗、教室信息、后台运行与开机自启。

## 两种典型用法

- 怕学生乱翻 → 只开「进入设置需要 PIN」；
- 别的都让值班老师能改，但**密钥、教室身份、退出**不许随手动 →
  关掉第一层，只勾那几项。

## 几个刻意的设计

- **验过一次就全部放行**（在这一次进入设置期间），不会为每一项各问一遍 ——
  那只会把 PIN 逼到便签上贴在电脑边。关掉窗口即重新上锁，解锁状态**绝不落盘**。
- **换 PIN 不会清掉已勾选的项目**：用户只是想换个口令，
  保护范围被悄悄重置成默认值的话，他不会收到任何提示。
- **PIN 没启用时一律放行**，哪怕配置文件里还留着上次勾的那几项。
- **退出保护默认关闭**。教室里那台机器是共用的，而"把喊话软件关掉"正是路过的人
  最可能干、后果又最直接的一件事（整间教室从所有老师的列表里消失，且没有任何提示）。

## 它拦得住什么

它拦的是"随手乱改"，**不是"防得住拿到这台机器的人"**：
配置就在本机，能读到文件的人删掉它即可绕过。这一点在界面上也写着，
免得学校以为它等同于账号口令。
