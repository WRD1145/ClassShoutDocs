# 学生名单

教师端底部导航的「名单」页。名单只存在**这台设备**上 ——
它是老师自己的备课资料，服务器只需要知道"某间教室收到了什么"，
没有任何理由持有一整份学生名册。

## 导入

每行一位学生：

```
姓名,学号,简写,小组
张三,20250101,小张,A组
李四,20250102,,B组
王五
```

- **只有姓名是必填**，后面三项留空就行；
- **可以直接从 Excel 里复制粘贴**，带表头、带空行、带引号都会自动处理，`#` 开头的行视为注释；
- 某一行没有姓名只会跳过那一行，并告诉你**是第几行**，不会整批失败。

可以导入好几份名单（一位老师通常教好几个班），下拉里切换。

## 标识格式：姓名（学号，简写，小组）

学生出现在喊话里时一律是这个格式，**括号内只放填了的那几项**：

| 名单里的内容 | 教室里显示的 |
|---|---|
| 张三,20250101,小张,A组 | 张三（20250101，小张，A组） |
| 李四,20250102,,B组 | 李四（20250102，B组） |
| 王五 | 王五 |

为什么要有括号里那几项：教室里那块屏上只有一行字，
老师按姓名叫人、而学生之间用简写互称、点名时又要对学号 —— 把填过的都带上，
看一眼就能确认叫的是不是自己。

为什么不填的就不显示：满屏的空括号既占地方又像是出了故障。

## 「叫这位」

名单里点「叫这位」会把这名学生**填进「文字」页**，这是最直接的呼叫方式。
要一次叫好几位、或者用模板拼句子，去[快速呼叫](/guide/call.html)。
