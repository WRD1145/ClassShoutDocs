# 贡献
感谢您为本文档做出贡献！

本文档基于 [VuePress](https://vuepress.vuejs.org/) 与 [vuepress-theme-hope](https://theme-hope.vuejs.press/) 搭建。了解它们的用法对编写本文档很有帮助。

本文档部署在 <https://docs.wrd1145.top/>，源码在 [WRD1145/ClassShoutDocs](https://github.com/WRD1145/ClassShoutDocs)。

## 贡献准则

使用小写文件名
    VuePress 对 URL 链接大小写敏感，使用包含大写字母的文件名可能会出现一些问题。在命名文档和文件夹时请使用小写字母，并用`-`分割每个单词，例如：
    xxx-xxx.md

## 合并更改

您可以向本项目发起 [Pull Request](https://github.com/WRD1145/ClassShoutDocs/pulls) 来合并您的更改。在发起 Pull Request 时，请简要地描述您做的更改。

更改合并以后，您可以在[最新版文档](https://docs.wrd1145.top/)中看到您的更改。

> 站点是中英双语的：中文页在 `src/` 下，英文页在 `src/en/` 下，
> 两边的目录结构一一对应。改了一个语言，记得另一个也改上 ——
> 只改一边的话，切到另一种语言看到的就是旧内容。
