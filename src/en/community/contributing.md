# Contributing
Thank you for contributing to this documentation!

This documentation is built with [VuePress](https://vuepress.vuejs.org/) and [vuepress-theme-hope](https://theme-hope.vuejs.press/). Knowing how they work will help you a lot when writing for this documentation.

This documentation is deployed at <https://docs.wrd1145.top/>, and the source code lives in [WRD1145/ClassShoutDocs](https://github.com/WRD1145/ClassShoutDocs).

## Contribution guidelines

Use lowercase file names
    VuePress is case-sensitive about URL links, so file names containing uppercase letters can cause problems. When naming documents and folders, use lowercase letters and separate each word with `-`, for example:
    xxx-xxx.md

## Merging changes

You can open a [Pull Request](https://github.com/WRD1145/ClassShoutDocs/pulls) against this project to merge your changes. When you open a Pull Request, briefly describe what you changed.

Once your changes are merged, you can see them in the [latest documentation](https://docs.wrd1145.top/).

> The site is bilingual (Chinese and English): Chinese pages live under `src/`, and English pages live under `src/en/`,
> with the two directory trees matching one to one. If you change one language, remember to change the other too —
> if you only change one side, switching to the other language shows you the old content.

## Still have questions?

You can [join the QQ group](./README) to discuss things with the developers and other users.
