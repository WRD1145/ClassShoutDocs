# Questions / help

1. Before you ask, look for the answer to your question in these places:
    - The documentation for the software
    - The Issues of the open-source project
    - Search engines ([Bing](https://cn.bing.com/), [Baidu](https://www.baidu.com/), and so on)
    
    If none of those places answers your question, then ask in the community.
    
    
    
2. When asking a question or asking for help, provide enough information. The more useful information you provide, the more likely you are to get help.

    
    
    
    
    Diagnosing any problem without error logs is like driving with your eyes closed.
    —— Apache official documentation, Getting Started chapter

    

If you do not know how to state your question effectively and precisely, we suggest that you read [How To Ask Questions The Smart Way](https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way/blob/main/README-zh_CN.md) first.
