# 快速呼叫

底部导航的「呼叫」页：用**组件**拼出要喊的话，选好学生，一次发出去。
它和「文字」页的区别是：文字页每次手打，而呼叫页是"同一套话反复喊给不同的人"。

## 组件

| 组件 | 输出 |
|---|---|
| 文字 | 你写的固定内容，例如「 来 」「 办公室」「：」 |
| 学生（姓名） | 这名学生的姓名 |
| 学生（简写） | 他的简写（没填就输出空） |
| 学生（学号） | 他的学号（没填就输出空） |
| 小组成员 | 他所在小组的**全部成员**，顿号分隔 |
| 随机叫人 | 抽中的这几位，顿号分隔（见下面的[随机叫人](#随机叫人)） |
| 教师名字 | 你自己的名字（含任教科目，例如「数学张老师」） |

**点一下**组件就加到拼装区末尾，也可以**直接拖过去**（桌面端；手机上拖放支持有限，点击即可）。
拼装区里的组件可以左右移动、删除；「文字」组件的内容能就地编辑。

## 两条拼装规则

1. **组件顺序拼接，不自动加空格。** 空格由「文字」组件自己带 ——
   想要「张三 来 数学张老师 办公室」，就在文字组件里写「 来 」和「 办公室」；
   而「张三」+「：请到办公室」要的是标点紧贴。自动加空格会让后者变成「张三 ：」。
2. **含「小组成员」时按小组归并成一句**，并且列出整份名单里同组的**全部**人
   （不只被勾上的那几位）—— 老师一次叫三个人，教室里要的是
   「请 张三、李四 来 数学张老师 办公室」这样一句，而不是连着闪三条几乎一样的喊话。
   没分小组的学生各算一组，不会被并进同一条。

## 模板

拼好的组件可以存成模板（保存 / 新建 / 删除）。默认给了一份「来办公室」的模板 ——
空白的组件面板对第一次用的人毫无提示作用。

改完还没保存时，下拉里会出现「（未保存）xxx」：宁可多一项，
也不要把老师刚拖进去的组件悄悄丢掉。

## 选学生

- 列表可以按**姓名 / 学号 / 简写**三种标识显示；
- **没填该字段的学生不会出现在那一档里** —— 否则会选到一个显示为空的条目，
  发出去一条没有学号的消息，而老师要到教室里才发现；
- 可以按小组一键勾选整组；
- 页面上有一行**预览**，发之前先看一眼。

发出去的展示参数（窗口/弹窗、字号、停留、朗读）与「文字」页当前那一套相同 ——
不另设一套，否则同一个应用里两条路发出去的字号会不一样。

## 随机叫人

组件面板里的「**随机叫人**」是另一种用法：不再自己挑学生，而是**按范围抽**。
模板里加上它，页面就切到随机模式（原来的学生列表让位给下面这几项设置）。

模板默认给了一份：

```
请 [随机叫人] 来回答这个问题
```

### 范围

| 设置 | 说明 |
|---|---|
| 小组 | 只在这一个小组里抽；「不限」就是全班 |
| 性别 | 只在男生 / 女生里抽；名单里没填性别的学生在这两档里不会被抽到 |
| 人数 | 一次抽几位，默认 1，最多 10 |
| 冷却 | 时间因子从满值衰减回 0 要多久，默认 **40 分钟**（约一节课），可选 20 / 40 / 60 / 90 分钟 |

四项都只存在**这台设备**上：它们是"这节课想怎么抽"的临时选择，
和名单一样没有理由跑到服务器上去。

### 抽中概率：隐形的时间因子

每位学生都带着一个界面上不显示的「时间因子」，规则是：

- 导入时一律是 `0.00`，上限 `1.00`；
- **因子越小越容易被抽到**：权重 = `1 − 因子`，最低留 `5%` 的边 ——
  刚叫过的人也不是完全没机会（否则连着抽两次永远轮不到他）；
- **抽中一次就把因子重置到 `0.95～1.00` 之间**（刚叫过 → 概率压到最低）；
- 之后随时间**线性**衰减回 0，衰减窗口就是上面那个「冷却」。

为什么不是纯随机：纯随机会出现"这节课连叫同一个学生三次"这种显然不公平的结果，
而老师想要的是"人人都会被叫到，但刚叫过的人先缓一缓"。

> 因子是**算出来**的，不是靠定时器一直改：存的是"因子值 + 写入时刻"，
> 当前值用一个减法推出来。所以应用关掉、电脑休眠、甚至系统时间被改过，
> 都不会让这套权重失准。

### 几个细节

- **预览不会把人抽掉**：随机模式下预览只说清"会从哪个范围里抽"，
  不会真的抽一次、也不会改任何人的因子。真抽是在你点发送的那一刻；
- 抽完之后页面上会写明**这次抽到的是谁**（"抽到：张三"），教室里也会喊出这一句；
- 抽中的学生会**立刻记下来并落盘**（因子与时刻）—— 抽了却不记，"刚叫过"就没有意义了；
- 模板里同时写了别的组件时按这个规矩解释：**姓名 / 简写 / 学号取抽中的第一位**（用来写"张三 请回答"），
  **小组成员取抽中的这几位所在的组**（去重）；
- 范围里一个人都没有（比如那个小组没填性别、而你只要男生）时不会发出空消息，
  会直接告诉你范围内没有人。

> 随机叫人目前只在 **App** 里可用。网页版那块呼叫按组件拼句子、勾学生，
> 不含随机模式 —— 时间因子与"谁刚被叫过"记在老师自己的设备上，
> 服务器上没有这份状态，放到网页上会变成两处各记一半。

## 在网页上呼叫

登录服务器账号之后，用浏览器打开服务器地址，**老师视图里也有一块「呼叫」**：
选模板、勾学生、点「预览会喊什么」先看一眼，再点「发送呼叫」。

它和 App 的规则是同一条 —— 因为两边用的是**同一段拼装代码**（组件顺序、空格、
按小组归并、来源里的科目都一致），不是照着重写一遍。

前提是名单在服务器上，而名单本来只存在老师自己的设备里，所以第一次用之前要同步一次：

> App 的「名单」页 → 底部「同步名单到服务器（网页呼叫用）」。
> 同步的是**当前这份名单**与全部呼叫模板；之后改了名单，再点一次即可。
> 同步过去的是姓名、学号、简写、小组、性别这几项，**时间因子不在其中**。

- 没同步过时，网页那一块会说清"去 App 同步"，不会让你对着一个空列表猜；
- 网页上只读不写：**名单与模板的编辑仍然只在 App 里**，网页是"用"而不是"管"；
- 预览可以先不勾班级（用你的默认科目拼一份给你看），真正发送必须勾班级。
