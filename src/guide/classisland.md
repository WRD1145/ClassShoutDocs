# 与 ClassIsland 联动

教室那台电脑上往往还挂着 [ClassIsland](https://github.com/ClassIsland/ClassIsland)（课表 / 打铃），
学生一整天看的都是它。所以「设置 → 喊话弹窗 → 提示方式」给了三个选择：

| 选项 | 行为 |
|---|---|
| 只看 ClassShout 弹窗（默认） | 就是自己那套弹窗 |
| 只看 ClassIsland 提醒 | 交给 ClassIsland 显示，走它自己的提醒通道（遮罩 / 音效 / 朗读都跟着它的设置走） |
| 两处都显示 | 两条通道各显示一份 |

ClassIsland 那一侧需要一个联动插件，**单独一个仓库**：
[WRD1145/ClassShoutCiPlugin](https://github.com/WRD1145/ClassShoutCiPlugin)（GPL v3）。
附件是 `.cipx`，放到 ClassIsland 数据目录的 `Plugins` 下即可。

> **插件版本要挑对**：ClassIsland **2.1.0.x 的宿主跑在 `net8.0-windows`** 上，
> **2.1.1 起才换成 `net10.0-windows`**，而插件的目标框架必须与宿主一致 ——
> 装错了不会报错，只是"插件装了但没反应"。
> 插件从 **1.0.3.0** 起按宿主自动取框架（2.1.0.1 那份是 `net8.0-windows`），
> 之前那份写死成 `net10.0-windows`，在 2.1.0.1 上加载不起来，请升级插件。

## 投递是怎么走的

```
ClassShout 教室端 ──POST http://127.0.0.1:45902/shout──▶ 插件 ──▶ ClassIsland 提醒
```

只绑回环地址，同网段其它机器连不上。插件没装、ClassIsland 没运行时投递会失败，
但**不影响喊话本身**：教室端日志只在头几次和每 20 次记一条，免得刷屏把真正的异常埋掉。

## 各类喊话投递什么

| 喊话 | 遮罩 | 正文 |
|---|---|---|
| 文字 | 张老师 喊话 | 老师发的字 |
| 语音（开始时） | 张老师 语音消息 | 语音消息 |
| 语音（识别结果出来后） | 张老师 语音消息 | 语音消息 + 换行 + 识别结果：… |
| 图片 | 张老师 图片消息 | 随图那句说明（提醒里放不下图，图在教室端大字区显示） |

**新喊话会顶掉上一条**：提醒是排队的，不主动取消的话，带识别结果的那条要排在
上一条的遮罩加正文播完（正文默认二十秒）之后才出现 —— 那时喊话早就结束了。
教室里本来也是这样：老师新喊一句，上一句就停了。

> 投递的报文里带一个 `kind` 字段（`text` / `voice` / `voiceTranscript` / `image`），
> 插件据此决定遮罩上写什么。旧版插件不认识它，会当成文字喊话 —— 不影响收到喊话。

## 按上课或下课时间发送

需要 ClassShout 联动插件 **1.1.0.0 或以上**。ClassIsland 先加载当天正在使用的档案，教室端每五秒读取当前课表摘要，经中继提供给有该教室授权的教师；不上传完整档案中的附加设置。

1. 在教师端登录并绑定目标教室，进入文字页，填写要发送的文字。
2. 在「按 ClassIsland 课表发送（当天）」卡片点「刷新绑定教室的课表」。
3. 选择第几节，选择上课或下课，以及之后 0–180 分钟；0 表示到点发送。
4. 点「将当前文字交给教室按课表发送」，等待教室本机保存确认。列表中可以查看和取消任务；取消也需要教室确认。

任务存在教室本机的 `classisland-schedules.json`。保存成功后，教师端退出或中继断开都不影响本地执行。教室端每次检查时依据 **ClassIsland 最新生效的课表** 计算时刻，换用新课表后不会继续按旧时刻触发。读取不到 ClassIsland 时不猜测时刻、不使用过期课表；恢复时超过三分钟的任务不补发。

第一版是当天一次性的文字任务，不支持跨天重复、图片或录好的语音。ClassIsland、联动插件和教室端都需保持运行，电脑需保持唤醒。检查间隔为五秒，因此触发可能晚几秒。教室离线、插件过旧、缺少课表、无授权或教室未确认保存都会显示明确原因；下发结果未知时先刷新任务列表核对，避免重复创建。
