# 教室端设置总览

教室端的设置在一个独立窗口里（点右上角的齿轮）。教室那块屏幕是给学生看的，
所以设置不占主界面。

| 卡片 | 管什么 |
|---|---|
| 设置口令 | 本机 PIN，以及哪几项要单独解锁（见 [PIN 保护](/guide/pin.html)） |
| 教室信息 | 教室名 —— 它出现在教师端列表、弹窗与服务器控制台上 |
| 朗读设置 | 音量、语速、朗读引擎（系统语音 / Edge 在线语音）、音色，以及试听 |
| 语音转文字 | 见[字幕](/guide/transcript.html) |
| 回复 | 教室里能怎么回老师：「知道了」、快捷回复、文字、语音，以及语音时长上限（见[教室回复](/guide/reply.html)） |
| 跨局域网喊话 | 中继服务器地址、连接/断开、本教室的 UUID 与口令 |
| 喊话默认怎么显示 | 发送方没指定时用哪一档（展示方式 / 字号 / 停留时间） |
| 喊话弹窗 | 见[屏幕弹窗](/guide/notification.html) |
| 后台运行 | 关闭窗口是否缩到托盘、是否开机自启 |
| 在线教师端 | 当前连着本教室的教师端列表 |
| 个性化 | 明暗（跟随系统 / 浅色 / 深色）与主题色（8 个预设或自填 `#RRGGBB`） |
| 版本与更新 | 检查更新、镜像源（见[安装与部署](/guide/install.html)） |
| 关于 | 版本号、运行环境、诊断信息、开发者模式 |

## 明暗：跟随系统 / 浅色 / 深色

「个性化」卡片里现在有两样：上面是「明暗」三个单选 —— 跟随系统、浅色、深色，
下面是原来的「主题色」色板（8 个预设或自填 `#RRGGBB`）。教师端在「设备」页的同一张卡片里，内容一样。

默认是**跟随系统**。这是相对旧版本的变化：以前明暗在 `App.axaml` 里写死成浅色，系统开着深色模式的
机器也只能显示浅色，而应用里没有任何地方能改。现在这类机器启动就是深色；想回到旧样子，把「明暗」
选成「浅色」一次，之后就一直记着。

改完立刻生效，不用重启。选「跟随系统」时是真的跟着系统走：系统在深色与浅色之间切换，应用当场跟着换，
不必再进设置点一次。

### 为什么默认改成跟随系统

写死浅色原本是为教室投影和手机在强光下的可读性 —— 这个理由本身没有变，问题在"写死"：系统已经是深色，
应用却一直亮着，而用户改不了。所以现在默认跟随系统，把选择权交回去；"投影和强光下选浅色更清楚"这句话
留作「明暗」下面的一行提示，不再替所有人做决定。

`Theme` 与 `SeedColor` 都存在 `appearance.json` 里，教室端、教师端（Android 与桌面）格式相同，
所以重启之后还是上次那一套。字段说明见[配置文件一览](/reference/config-files.html)。

> 换的不只是背景。浅色和深色都是从同一个「主题色」推导出来的两套配色，切明暗时主色、容器、描边、
> 文字会一起换；反过来改「主题色」，浅色和深色两边都会跟着变，不需要分别设两遍。

## 开发者模式在哪

设置页最底下「关于」里，**在版本号上连点 10 次**（间隔超过 1.5 秒就重新计数；
点到第 5 次会提示还差几次）。解锁后多出三样：字体回退诊断、打开配置目录、
复制诊断信息 —— 都是排障用的，平时不必开。关闭方式：删掉本机配置目录里的
`developer.json`。

**「版本与更新」卡片里那一行版本号也认同一个手势。** 界面上有两处显示版本号，
而人会去点自己最先看到的那一行；只让其中一处能点开，用户就会以为开发者模式没了。
两处共用同一套规则，从任一入口解锁，另一处的开发者内容会立即跟着展开。

教师端（「设备」页）完全一样。

## 关闭窗口不是退出

点关闭按钮不会退出，而是缩到通知区域继续接收喊话 —— 教室里顺手点一下 ×
不该让全班失联。要完全退出请右键托盘图标选「退出」。

## 教室身份为什么是只读的

「跨局域网喊话」卡片里能看到本教室的 **UUID** 与 **口令**，都能一键复制，
但**没有"重新生成"的按钮**。

教室里那台机器是给值班老师和学生共用的，而"重置"的真实含义是
"这台电脑从此变成另一间教室"：已绑定的教师端全部失效、口令要重新抄给每一位任课老师。
一个误触就要把口令重发一圈，这个代价和"重置"这个词给人的感觉完全不成比例。
真要重来（比如这台机器换教室了）请到服务器控制台上做 ——
那里看得见影响范围，也能一次性通知到人。

## Linux 上跑教室端

教室端也能跑在 Linux 上，但**系统朗读需要系统里有 `spd-say` 或 `espeak-ng`**。
没有的话启动时日志里会写一行提醒，建议在朗读设置里改用 Edge 在线语音，
否则教室里不会出声。

托盘、桌面通知、播放与录音各自要装什么，见 [Linux 上的教室端](/guide/linux.html)。
