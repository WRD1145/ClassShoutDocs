# 教室端设置总览

教室端的设置在一个独立窗口里（点右上角的齿轮）。教室那块屏幕是给学生看的，
所以设置不占主界面。

| 卡片 | 管什么 |
|---|---|
| 设置口令 | 本机 PIN，以及哪几项要单独解锁（见 [PIN 保护](/guide/pin.html)） |
| 教室信息 | 教室名 —— 它出现在教师端列表、弹窗与服务器控制台上 |
| 朗读设置 | 音量、语速、朗读引擎（系统语音 / Edge 在线语音）、音色，以及试听 |
| 语音转文字 | 见[字幕](/guide/transcript.html) |
| 回复 | 教室里能怎么回老师：「知道了」、快捷回复、文字、语音，以及语音时长上限（见[教室回复](/guide/reply.html)） |
| 跨局域网喊话 | 中继服务器地址、连接/断开、本教室的 UUID 与口令 |
| 喊话默认怎么显示 | 发送方没指定时用哪一档（展示方式 / 字号 / 停留时间） |
| 喊话弹窗 | 见[屏幕弹窗](/guide/notification.html) |
| 后台运行 | 关闭窗口是否缩到托盘、是否开机自启 |
| 在线教师端 | 当前连着本教室的教师端列表 |
| 个性化 | 明暗（跟随系统 / 浅色 / 深色）与主题色（8 个预设或自填 `#RRGGBB`） |
| 版本与更新 | 检查更新、镜像源（见[安装与部署](/guide/install.html)） |
| 关于 | 版本号、运行环境、诊断信息、开发者模式 |

## 启动时自动连接服务器

教室里那台电脑每天开机，没人会去点「连接服务器」；而它一旦没连上，那节课的喊话就安静地送不到 ——
教室里没有任何提示。所以只要**成功连过一次**，这件事就被记住：之后每次启动自己连。

开关在「跨局域网喊话」那张卡里（**启动时自动连接**）。第一次连上后它自动打开，想彻底不连就在那里关掉。

手动点「断开」**不会**关掉它：那只是这一次不想连（检修网络之类），下次开机照旧自己连上。

失败不弹框 —— 原因落在日志与那张卡上，与手动连接时看到的一样。连接在窗口出来之后才开始，
不在启动时干等：等服务器应答会让教室端白屏几秒，看起来像卡死。
## 明暗：跟随系统 / 浅色 / 深色

「个性化」卡片里现在有两样：上面是「明暗」三个单选 —— 跟随系统、浅色、深色，
下面是原来的「主题色」色板（8 个预设或自填 `#RRGGBB`）。教师端在「设备」页的同一张卡片里，内容一样。

默认是**跟随系统**。这是相对旧版本的变化：以前明暗在 `App.axaml` 里写死成浅色，系统开着深色模式的
机器也只能显示浅色，而应用里没有任何地方能改。现在这类机器启动就是深色；想回到旧样子，把「明暗」
选成「浅色」一次，之后就一直记着。

改完立刻生效，不用重启。选「跟随系统」时是真的跟着系统走：系统在深色与浅色之间切换，应用当场跟着换，
不必再进设置点一次。

### 为什么默认改成跟随系统

写死浅色原本是为教室投影和手机在强光下的可读性 —— 这个理由本身没有变，问题在"写死"：系统已经是深色，
应用却一直亮着，而用户改不了。所以现在默认跟随系统，把选择权交回去；"投影和强光下选浅色更清楚"这句话
留作「明暗」下面的一行提示，不再替所有人做决定。

`Theme` 与 `SeedColor` 都存在 `appearance.json` 里，教室端、教师端（Android 与桌面）格式相同，
所以重启之后还是上次那一套。字段说明见[配置文件一览](/reference/config-files.html)。

> 换的不只是背景。浅色和深色都是从同一个「主题色」推导出来的两套配色，切明暗时主色、容器、描边、
> 文字会一起换；反过来改「主题色」，浅色和深色两边都会跟着变，不需要分别设两遍。

## 开发者模式在哪

设置页最底下「关于」里，**在版本号上连点 10 次**（间隔超过 1.5 秒就重新计数；
点到第 5 次会提示还差几次）。解锁后多出三样：字体回退诊断、打开配置目录、
复制诊断信息 —— 都是排障用的，平时不必开。关闭方式：删掉本机配置目录里的
`developer.json`。

**「版本与更新」卡片里那一行版本号也认同一个手势。** 界面上有两处显示版本号，
而人会去点自己最先看到的那一行；只让其中一处能点开，用户就会以为开发者模式没了。
两处共用同一套规则，从任一入口解锁，另一处的开发者内容会立即跟着展开。

教师端（「设备」页）完全一样。

## 关闭窗口不是退出

点关闭按钮不会退出，而是缩到通知区域继续接收喊话 —— 教室里顺手点一下 ×
不该让全班失联。要完全退出请右键托盘图标选「退出」。

## 教室身份为什么是只读的

「跨局域网喊话」卡片里能看到本教室的 **UUID** 与 **口令**，都能一键复制，
但**没有"重新生成"的按钮**。

教室里那台机器是给值班老师和学生共用的，而"重置"的真实含义是
"这台电脑从此变成另一间教室"：已绑定的教师端全部失效、口令要重新抄给每一位任课老师。
一个误触就要把口令重发一圈，这个代价和"重置"这个词给人的感觉完全不成比例。
真要重来（比如这台机器换教室了）请到服务器控制台上做 ——
那里看得见影响范围，也能一次性通知到人。

## Linux 上跑教室端

教室端也能跑在 Linux 上，但**系统朗读需要系统里有 `spd-say` 或 `espeak-ng`**。
没有的话启动时日志里会写一行提醒，建议在朗读设置里改用 Edge 在线语音，
否则教室里不会出声。

托盘、桌面通知、播放与录音各自要装什么，见 [Linux 上的教室端](/guide/linux.html)。

## 第三方 HTTP 语音

在朗读引擎中选择「第三方 HTTP 语音」，填写完整服务地址、可选音色和 Bearer 密钥，选择是否失败回退系统语音，点「保存第三方语音配置」后试听。密钥存于教室本机 `classroom-speech.json`，不应把此文件或配置目录分享给他人。

这是 ClassShout 的通用适配协议，不保证任意厂商地址直接兼容：服务接受 `POST` JSON，字段为 `text`、`voice`、`rate`（-10 至 10）和 `format: "wav"`，返回原始 **16 位 PCM WAV**。厂商格式不同需编写转换服务。可使用局域网离线合成服务；服务无密钥时允许 HTTP，携带密钥的 HTTP 需要明确勾选允许明文传输。HTTPS 严格验证证书，不跟随重定向。

单次请求限时 30 秒、最多 10000 字、响应最多 8 MiB。朗读继续使用原有队列和消息回执，只有实际播放完成才报告完成。停止、超时、解码失败会取消或失败；若开启回退，则改由系统语音朗读。

## 本机 IPC

1.22.0 起提供独立「本机 IPC」卡片，配置位于 classroom-ipc.json，监听 127.0.0.1:45903，默认关闭并要求令牌。外部应用的路由、鉴权和 OpenAPI 见[IPC 接口文档](/reference/ipc.html)。旧版 extensions.json 会保留并自动迁移，已有令牌不变。

## 插件管理

当前开发版将插件移到设置窗口独立的「插件」标签，「常规」页不再展开插件列表；此导航调整尚未包含在 1.22.0 中。已锁定时先在「常规」页解锁。切换标签或关闭设置不会停止、重启插件，也不会改变 IPC 开关。

1.22.0 起将插件独立管理，支持本地包安装、搜索、详情、启停、重启与卸载。新插件使用 DI 和独立程序集加载上下文，不需要开启 IPC；安装后默认禁用。配置位于 classroom-plugins.json。SDK、清单和示例见[插件开发](/dev/plugins.html)。仅启用可信代码；程序集隔离不是安全沙箱。

## 本地铃声

铃声卡片可添加、修改、禁用、删除和试听计划，修改后点保存铃声。计划保存在教室本机的 bells.json，到点使用本地合成音，不依赖教师端或中继连接。时刻使用 HH:mm；周几位值周一到周日为 1、2、4、8、16、32、64，相加选择多天，工作日为 31，每天为 127。

电脑必须开机、保持唤醒且教室端运行；关机、休眠时不会响，也不会补响过去的计划。同时到点的铃声若与正在播放的铃声重叠会跳过并记录原因。开始提醒可关闭，铃声音量独立设置。保存失败和播放失败会写入日志。


## 连接诊断

设置中的「连接诊断与配置迁移」可以一键检查本机教室接收端口、中继健康接口、TTS 和 ClassIsland 当天课表。每项分别显示结果和原因；中继健康并不表示账号授权或教室投递成功，扬声器是否正常仍需试听。系统语音只检查引擎是否可用，Edge 只检查音色接口；第三方 TTS 实际合成一句测试语音并验证 WAV，但不播放，可能产生服务调用费用。

「导出脱敏诊断报告」仅包含检查项目、固定原因、耗时和时间，不包含服务器地址、账户、密钥、响应正文或原始日志。请求超时和异常不会把服务端回显内容放进报告。健康检查严格校验 HTTPS 证书，不沿用宽松证书选项。

## 配置备份与迁移

先保存配置，再点「导出配置备份」。教室端备份包含铃声规则和自定义音频、快捷回复组件，以及 TTS 引擎、音色、音量、语速和回退选项。备份含自定义文字和音频，请妥善保管。

默认排除登录信息、教室身份、服务器、IPC 令牌和插件执行清单；第三方 TTS 密钥和服务地址也不导出，因为地址自身可能包含凭据。在新电脑选择备份后先查看覆盖预览，再「确认覆盖并导入」，**重启应用后使用**。导入保留目标电脑已有的地址、密钥和登录信息；新电脑需要重新填写 TTS 地址及密钥，缺少音色时使用本机默认音色。它不会自动启用插件。

导入覆盖本端的对应设置，不合并列表；不适用于本端的项目不会写入。格式版本必须受支持，文件最多 16 MiB；未知字段和无效组件会被拒绝。文件逐一原子替换，写入失败会恢复此前已写入的配置；若权限阻止恢复，会明确提示回滚失败。

若朗读设置受 PIN 保护，须先解锁再导入；即使已打开覆盖预览，确认时也会再次检查锁定状态。连接诊断仍可使用。
