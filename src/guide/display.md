# 每条喊话自己的显示参数

「这条怎么显示」是**跟着每一条喊话走**的，不是全局设置 ——
班主任想让一句话占满整块屏、科任老师只想要一条角落提示，两种都很常见。

| 项 | 可选 | 默认 |
|---|---|---|
| 展示方式 | 窗口（占满教室大字区）/ 弹窗（屏幕边缘提示卡） | 窗口 |
| 文字大小 | 小 / 中 / 大 / 特大 | 中 |
| 停留时间 | 10 秒 / 20 秒 / 30 秒 / 1 分钟 / 常驻 | 20 秒 |
| 语音播报 | 开 / 关 | 开 |

选完会记住，下次打开还是它 —— 讲评试卷时习惯用「特大字 + 常驻」的老师，
不该每节课都重选一遍。

## 教室端还有一套默认值

教室端 → 设置 → 「喊话默认怎么显示」里可以设「发送方没有特别指定时用哪一档」。
两套值各管各的：

- 教师端那套是**这位老师上次用的**，存在他自己的设备上；
- 教室端那套是**没人指定时用哪一档**，存在教室里那台机器上。

所以旧版教师端发来的喊话照样有合理的显示效果，而不是什么都不显示。

## 几条实现上的取舍

- **「常驻」与「没指定」用不同取值区分**（0 与负数）。混起来的话，
  没选停留的喊话会永久留在屏幕上 —— 那是教室里最不希望发生的默认行为。
- **还在朗读时不收走内容**：停留时间到了但话没说完，就等朗读结束再收，
  否则教室里会出现"话还在说、字已经没了"。
  反过来，读完了但停留还没到，内容继续留着。
- **弹窗模式不点亮大字区**：选了弹窗的人要的就是"别占屏"。
- 同一档字号在教室大字区与弹窗里用的是**两套像素值**（映射由 Core 统一决定）：
  弹窗只占屏幕一角，用大字区的尺寸会直接溢出屏幕。
