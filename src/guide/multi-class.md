# 一次发给多个班级

教好几个班的老师，不必一间一间来。在「文字」页的「这条发给谁」里勾几个班，
这一条就同时发到每一间。

- 默认只勾**当前绑定**的那一间，标着「当前绑定」徽标；
- 勾选在列表刷新后会保留（去设备页切了个教室回来，勾选不会丢）；
- 只有保存了一间教室时整块不显示 —— 只有一间的话，"选择"没有意义；
- 发送结果会如实报出"哪几间没送到"，失败时能直接看到是哪个班。

## 语音喊话只发当前绑定那间

声音是从某一个教室的喇叭出来的，同时往几个班播没有意义。
所以「这条发给谁」只影响文字（与图片文字）喊话。

## 它是怎么做到的

多班发送对每个目标**按需绑定**：发送这一刻拿一个有效的令牌，发完就留着复用，
而不是让教师端同时挂着五条长轮询（那是五倍的连接与心跳）。

- 令牌失效（服务器重启过）时会自动重绑一次再发 ——
  只试一次就放弃的话，多班喊话会在服务器重启之后一直失败到有人手动切换一遍班级为止。
- 逐间**串行**发送，不是并发：三五个班串行只多几百毫秒，
  但日志顺序清楚、出错时能直接指出是哪一间。
- 登出时会一并断掉这些临时绑定。
