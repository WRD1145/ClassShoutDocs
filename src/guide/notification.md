# 屏幕弹窗

教室端收到喊话时，在**屏幕边缘**弹出一张小卡片，显示老师姓名、时间与喊话内容（图片喊话会带上图）。

两个刻意的设计：

- **不抢焦点**：老师正在投屏或操作时，提示不该把当前窗口顶下去；
- **不进 Alt+Tab**：它是通知，不是一个应用窗口。

## 可设置的项（教室端 → 设置 → 喊话弹窗）

| 项 | 说明 |
|---|---|
| 是否弹窗 | 关掉就只有大字区显示 |
| 出现位置 | 四个角任选 |
| 提示方式 | 只看 ClassShout 弹窗 / 只看 ClassIsland 提醒 / 两处都显示 |
| 置顶档位 | 不置顶 / 普通置顶 / 强制置顶（周期性重申） |
| 停留时长 | 自动消失的秒数；0 表示不自动消失 |

停留时长还有一层：**发送方可以指定这一条停多久**（见[显示参数](/guide/display.html)），
那时以发送方指定的为准。发送方选了「只在大字区显示」时，弹窗不参与。

## 「UIA 置顶」为什么是灰的

Windows 存在"窗口段"机制，普通置顶窗口盖不住更高窗口段的东西（开始菜单、任务管理器、
通知中心等）。要盖住它们必须持有 **UIAccess** 令牌，
而 Windows 要求 UIAccess 程序**必须数字签名且安装在安全目录**（如 `Program Files`），
否则程序直接无法启动。

未签名的便携版本做不到这一层。把这一项列出来并写明"暂不可用"，比藏起来更好 ——
它说明白了这个能力不是漏做，而是有前置条件。
