# 学生名单

教师端底部导航的「名单」页。名单只存在**这台设备**上 ——
它是老师自己的备课资料，服务器只需要知道"某间教室收到了什么"，
没有任何理由持有一整份学生名册。

## 导入

每行一位学生，一共五列：

```
姓名,学号,简写,小组,性别
张三,20250101,小张,A组,男
李四,20250102,,B组,女
王五
```

- **只有姓名是必填**，后面四项留空就行；
- **可以直接导入表格文件**：`.xlsx` / `.xlsm` / `.xls` 与 `.csv` / `.txt` 都行
  （名单页上的「从文件导入」，手机上会打开系统文件选择器）。
  电脑上的名单九成是表格，而"先另存为 CSV"这道工序恰恰最容易出错 ——
  另存时选错编码、或者 Excel 把学号前面的 0 吃掉。直接读表格就没有这一步；
- **可以直接从 Excel 里复制粘贴**，带表头、带空行、带引号都会自动处理，`#` 开头的行视为注释；
- 某一行没有姓名只会跳过那一行，并告诉你**是第几行**，不会整批失败；
- **表头可有可无**：认得出「姓名」那一行就跳过它，认不出就按第一行也是学生来读；
- 表格文件只读**第一个工作表**，并把**工作表名当作名单名**（比文件名更贴近内容，
  例如工作表叫「三年二班」时，导入后名单就叫「三年二班」而不是「名单(1)」）。

### 五列各自有什么用

| 列 | 说明 |
|---|---|
| 姓名 | 必填。缺了这一行没有意义 |
| 学号 | 显示与点名用。表格里常常是数字，导入时会写成整数（不会变成 `20250101.0`） |
| 简写 | 学生之间互称的短称呼，例如「小张」 |
| 小组 | 呼叫页可以按小组一键勾选整组；[随机叫人](/guide/call.html#随机叫人)也能只抽某一组 |
| 性别 | 只用于[随机叫人](/guide/call.html#随机叫人)的范围筛选。`男`/`女`/`男生`/`女生`/`M`/`F`/`1`/`0` 都认，认不出来的留空 |

名单里的每位学生还带着一个**隐形的时间因子**，导入时一律是 `0.00`。
它是随机叫人用的，"刚被叫过的人先缓一缓"就靠它，界面上不显示（见[随机叫人](/guide/call.html#随机叫人)）。

可以导入好几份名单（一位老师通常教好几个班），下拉里切换。

## 名单按班隔离，班主任还可以统一一份

名单是**按班隔离**的：给二班导入的名单不会被当成三班的用 ——
喊话与呼叫永远发生在某一个班里，而"叫人"必须只叫得到这个班的人。

在此之上，**班主任**可以给某个班上传一份**全班统一使用**的名单，并决定要不要设为强制：

| 那个班的情况 | 实际用哪份名单 |
|---|---|
| 班主任传了、并设为**强制** | 一律用班主任那份；你连「从文件导入」的入口都没有 |
| 班主任传了、没有强制 | 你自己传了就用你自己的；没传就用班主任那份 |
| 班主任没传 | 用你自己的 |

名单页上写着"这个班现在用谁的名单"，被强制时也会写明原因（以及该找谁取消）。
被强制的班里，你自己那份名单**不会被删掉**，只是暂时不生效 —— 班主任一取消强制就立刻回来。

> 为什么要有个"强制"开关：一个班到底按哪份名单叫人，必须**只有一个答案**。
> 两位老师各录一份时，同一个班里可能一位老师叫得出人、另一位叫不出来，
> 或者叫出来的人对不上（转学生补了没有、谁已经调班了）。细则见[账号与权限](/guide/roles.html)。

## 标识格式：姓名（学号，简写，小组）

学生出现在喊话里时一律是这个格式，**括号内只放填了的那几项**：

| 名单里的内容 | 教室里显示的 |
|---|---|
| 张三,20250101,小张,A组 | 张三（20250101，小张，A组） |
| 李四,20250102,,B组 | 李四（20250102，B组） |
| 王五 | 王五 |

为什么要有括号里那几项：教室里那块屏上只有一行字，
老师按姓名叫人、而学生之间用简写互称、点名时又要对学号 —— 把填过的都带上，
看一眼就能确认叫的是不是自己。

为什么不填的就不显示：满屏的空括号既占地方又像是出了故障。

## 「叫这位」

名单里点「叫这位」会把这名学生**填进「文字」页**，这是最直接的呼叫方式。
要一次叫好几位、或者用模板拼句子，去[快速呼叫](/guide/call.html)。
