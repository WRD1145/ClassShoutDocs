# 语音转文字（字幕）

教室端把收到的**语音喊话**识别成文字，摆到教室那块屏的大字区当字幕，
并记进运行日志。教室音响听不清、或者班里有听障学生时，看见字才算真的听见。

配置在**教室端**：设置 → 「语音转文字」。

| 项 | 说明 |
|---|---|
| 接口地址 | 默认 `https://api.openai.com/v1`。任何兼容 `/v1/audio/transcriptions` 的服务都能填，例如自建的 whisper 服务 |
| 密钥 | 只存在这台教室电脑上，不上传、不写日志 |
| 模型 / 语言 | 默认 `whisper-1` / `zh`，语言留空则由服务自行判断 |

## 为什么配在教室端，而不是老师手机上

音频是流到教室那台电脑上才放出来的，识别放在这里，识别的就是教室里**真正响过**的那一段。
放在手机上识别的是老师自己麦克风里的声音 —— 教室里到底放出来什么、有没有听清，
手机那边并不知道。

## 它的行为

- **识别是"附加"的一步**：网络不通、密钥填错都只记一条日志，
  不影响喊话的声音，也不会弹框打断教室里的人。
- **字幕停留 60 秒**后收回待机。
- 单次最多转写**前 5 分钟**：识别接口收的是整个音频文件，再长就要在内存里堆着了。
- 识别结果比声音晚到几秒。这期间若来了新的喊话，旧的那条**只写日志**、
  不再去改大字区 —— 否则新老师正在说的话会被上一位的迟到字幕顶掉。

## 它也会投给 ClassIsland

识别成功后会再投一条通知，正文带上识别出的字。详见 [与 ClassIsland 联动](/guide/classisland.html)。
