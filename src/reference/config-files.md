# 配置文件一览

所有本机配置都在用户数据目录里，不在程序旁边 ——
程序可能被装在只读位置，而且同一台机器上不同账户应当有各自独立的身份。

- Windows：`%LOCALAPPDATA%\ClassShout\`
- Linux：`~/.local/share/ClassShout/`（或 `$XDG_DATA_HOME`）
- 可用环境变量 `CLASSSHOUT_DATA_DIR` 指定到别处（便携安装、自检都靠它）

## 教室端

| 文件 | 内容 | 含凭据 |
|---|---|---|
| `classroom.json` | 教室名、UUID、口令、服务器地址、「启动时自动连接」，以及「允许不信任的 TLS 连接」 | **是**（口令） |
| `classroom-notification.json` | 弹窗设置与喊话默认展示参数 | 否 |
| `classroom-speech.json` | 朗读设置（引擎、音色、音量、语速） | 否 |
| `classroom-stt.json` | 语音转文字的接口地址与**密钥** | **是**（密钥） |
| `classroom-reply.json` | 回复设置（快捷回复、知道了、文字/语音开关、语音时长上限） | 否 |
| `settings-lock.json` | PIN 的派生值与盐、哪几项受保护 | **是**（派生值，不含明文） |
| `appearance.json` | 主题色与明暗（两端共用同一份格式，见下） | 否 |

### `classroom-reply.json`

回复的全部设置都在这个文件里。键名是首字母大写（`Enabled`、`QuickReplies`）—— 手改时
照抄文件里的写法；大小写对不上，那一项会被当成不认识的字段跳过：应用不报错，只是改了不生效。

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `Enabled` | 布尔 | `true` | 总开关。关掉之后教室那块屏上不出现任何回复入口 |
| `ShowAcknowledge` | 布尔 | `true` | 是否显示「知道了」按钮 |
| `AcknowledgeTemplate` | 字符串 | `{教室}知道了` | 「知道了」发出去的那句话，可写占位符；留空则退回 `AcknowledgeComponents`（默认是教室名 +「知道了」） |
| `AllowText` | 布尔 | `true` | 允许教室里现打一句文字回复 |
| `AllowVoice` | 布尔 | `true` | 允许语音回复；没有麦克风的教室应当关掉它 |
| `VoiceMaxSeconds` | 整数 | `15` | 语音时长上限（秒）。读入与保存时都收进 3–60 |
| `QuickReplies` | 数组 | 收到 / 马上 / 没问题 | 快捷回复，最多 6 条；多出的在读入或保存时被截掉 |

`QuickReplies` 的每一条：

| 字段 | 类型 | 含义 |
|---|---|---|
| `Id` | 字符串 | 这一条的标识，编辑时靠它找回原来那一条 |
| `Label` | 字符串 | 按钮上的文字；为空时用拼出来的内容 |
| `Components` | 数组 | 回复由哪些组件拼成 |
| `Components[].Kind` | 字符串 | 组件种类：`text`、`classroom`、`teacher`、`time`、`original` |
| `Components[].Text` | 字符串 | `Kind` 为 `text` 时的那段文字；可以写 `{教室}` `{老师}` `{时间}` `{原话}` |

`Components` 里 `Kind` 不是 `text` 的组件不看 `Text`：`classroom`、`teacher`、`time`、
`original` 各自取教室名、老师称呼、回复时刻与原喊话，和占位符是同一套值。
认不出来的 `{...}` 原样留着，不会被删掉。

> `AcknowledgeComponents` 是 1.15.0 起的组件写法，只有在 `AcknowledgeTemplate` 为空时
> 才用得上；正常改模板就行，不必碰它。

## 教师端

| 文件 | 内容 | 含凭据 |
|---|---|---|
| `teacher.json` | 服务器地址、登录令牌、已保存的教室（**含口令**）、任教科目（默认 + 按班级），以及「允许不信任的 TLS 连接」 | **是** |
| `teacher-display.json` | 上次用的展示参数 | 否 |
| `teacher-schedule.json` | 本机定时喊话（待发 + 最近处理完的） | 否 |
| `schedule-audio/` | 本机定时语音的 WAV（发出去或取消之后就删掉） | 否 |
| `teacher-rosters.json` | 学生名单（可能有好几份，**按班各用各的**）。每位学生除了姓名/学号/简写/小组/性别，还带着隐形的**时间因子**与它的写入时刻（[随机叫人](/guide/call.html#随机叫人)用） | 否 |
| `teacher-calls.json` | 呼叫模板（组件拼装出来的那几套），以及随机叫人的范围与冷却（小组 / 性别 / 人数 / 衰减分钟） | 否 |
| `teacher-phrases.json` | 常用语（文字页那排一键填入的短语） | 否 |
| `shout-history.json` | 最近 100 条喊话内容 | 否 |
| `appearance.json` | 主题色与明暗 | 否 |
| `developer.json` | 开发者模式开关（连点版本号 10 次解锁） | 否 |
| `update.json` | 检查更新的设置（镜像源列表、代理、上次检查的结果） | 否 |
| `log.json` | 日志详细程度（**两端共用同一份格式**，见下） | 否 |

## 个性化（`appearance.json`）

主题色和明暗都在这一个文件里，两端的格式相同（教师端在 Android 与桌面上也是同一套格式）。
键名照旧是首字母大写；写成小写的 `theme` 会被当成不认识的字段跳过 —— 应用不报错，只是改了不生效。

| 字段 | 类型 | 含义 |
|---|---|---|
| `SeedColor` | 字符串 | 主题色的种子，`#RRGGBB`。浅色与深色两套配色都由它推导 |
| `Theme` | 整数 | 明暗：`0` 跟随系统（默认）、`1` 浅色、`2` 深色 |

`Theme` 读到范围外的值（比如手改成 `3`）时按 `0` 跟随系统处理 —— 设置写坏不该让界面留在一套读不清的颜色上。

> 明暗改的是整套配色，不只是背景：主色、容器、描边、文字都跟着换，因为浅色和深色是同一颗
> `SeedColor` 推导出来的两套。只想换颜色时改 `SeedColor` 一处就够，两套都会跟着变。

## 运行日志

日志**默认写在软件目录下的 `logs/`**（不是用户数据目录）—— "日志在哪"与"软件在哪"
是同一件事，而找日志的人多半正站在那台机器前面。按天一个文件、只留最近 7 天。

装在只读位置时逐级退，退到哪一级会显示在设置页的「关于」里：

1. 环境变量 `CLASSSHOUT_LOG_DIR`（压缩包里的启动脚本会指到软件目录下的 `logs/`）；
2. 程序目录下的 `logs/`；
3. 用户数据目录下的 `logs/`（下面的表里也有它）。

| 文件 | 内容 |
|---|---|
| `logs/classshout-2026-09-26.log` | 当天的运行日志（界面上的那份同时落到这里） |

日志行里带着级别与来源：`2026-09-26 19:14:09 [信息 网络] 已连上教室`。

### 详细程度（`log.json`）

两端的运行日志卡片上都有一个档位下拉框，改完立刻生效、也立刻存进 `log.json`：

| 档位 | 记什么 |
|---|---|
| `Trace`（跟踪） | 每一次广播、每一帧收发 —— 最详细，日志会长得很快 |
| `Debug`（调试） | 连接、发现、重试的过程。**排查「扫不到教室」「这条到底发出去没有」看这一档** |
| `Info`（信息，默认） | 正常操作与结果 |
| `Warning`（警告） | 只记警告与错误 |
| `Error`（错误） | 只记错误 |

低于设定档位的日志**既不显示在界面上，也不落盘**。档位认不出来时退回 `Info` ——
设置写坏不该让日志整个消失。

> 为什么要有这个开关：默认档位看不到"广播发到哪个地址、谁回了什么"，
> 而那正是连接类问题的全部线索；但平时把它们全记下来，日志会变成流水账。
> 服务器那份日志用环境变量 `CLASSSHOUT_LOG_LEVEL` 调同一套档位（见[中继服务器](/guide/relay.html)）。

> 任教科目存在 `teacher.json` 里只是一份**缓存**（局域网直连那条路不经过服务器，
> 名字得由教师端自己贴），权威的那份在服务器账号上。

> `teacher.json` 里有明文口令，`classroom-stt.json` 里有 API 密钥。
> 这两个文件是"这台设备被拿走就等于这些凭据也一起被拿走"的那一类 ——
> 这是有意的取舍（见[跑通第一个班级](/guide/first-class.html)里那段说明），
> 但要把它当凭据对待：不要把整个目录打进备份镜像再公开分享。
